# 11: Project detail: timeline and report

**What to build:** Opening a project shows its header (category, status, progress, target outcome), its work-entry timeline, and a project-scoped report. The user can log time against the project from here.

**Blocked by:** 06 (Quick capture and today's list), 10 (Initiatives portfolio)

**Status:** ready-for-agent

- [ ] The project detail route opens from the portfolio and from a direct link.
- [ ] The header shows category, status, progress, and target outcome.
- [ ] The timeline lists the project's work entries newest first.
- [ ] The report shows project-scoped totals and support interactions from that project's entries.
- [ ] Log time creates an entry attributed to this project.
- [ ] An archived project is read-only until restored.
- [ ] Loading, empty, error, and validation states are handled.
- [ ] Connect and gRPC-Web tests cover detail, timeline, report, and archived behaviour.
