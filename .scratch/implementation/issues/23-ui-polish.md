# 23: UI polish

**What to build:** Every screen feels like one product: the four themes, comfortable and compact densities, keyboard shortcuts, visible focus, loading and empty and error states, and accessible contrast. The five-second capture path stays fast.

**Blocked by:** 04–20 and 22 (all feature slices)

**Status:** ready-for-agent

- [ ] System, Light, Dark, and High Contrast themes work with the Deep Teal seed.
- [ ] Comfortable and Compact densities apply consistently.
- [ ] Keyboard shortcuts work: `T`, `N`, `S`, `G` then `T`/`L`/`I`/`C`, `/`, and `?`.
- [ ] Every screen has explicit loading, empty, error, validation, and success states.
- [ ] Focus rings are visible and full keyboard operation is possible.
- [ ] Colour pairs meet WCAG AA; timer state is conveyed by more than colour.
- [ ] Times and durations use tabular figures and ISO-like date order.
- [ ] No regression in the quick-capture flow.
