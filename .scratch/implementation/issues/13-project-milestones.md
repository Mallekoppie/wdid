# 13: Project milestones

**What to build:** A user can add milestones to a project with a title, an optional due date, and a done flag, then edit, complete, and delete them. The project report shows milestone completion alongside the time invested.

**Blocked by:** 11 (Project detail: timeline and report)

**Status:** ready-for-agent

- [ ] A milestone can be created with a title, optional due date, and done flag.
- [ ] A milestone can be edited, marked done or not done, and deleted.
- [ ] Milestones appear on the project detail and can be added from it.
- [ ] The project report shows how many milestones are complete.
- [ ] Milestones survive a restart.
- [ ] Loading, empty, error, and validation states are handled.
- [ ] Connect and gRPC-Web tests cover create, update, complete, delete, and report counts.
